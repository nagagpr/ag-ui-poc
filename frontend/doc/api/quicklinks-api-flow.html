3. Step by step

0

The request (Postman)

GET {{baseUrl}}/v1/quick-links?limit=10&offset=0
Authorization: Bearer <token from "POST Okta Token">

limit = rows per page, offset = rows to skip. The token comes from the Okta Token request in the same collection.

1

App registers the router VERIFY

app.include_router(quick_links_router, prefix="/v1")

Search the repo for quick_links_router to find the real line.

2

Router endpoint VERIFY

Typical shape — confirm in quicklinks/router/quick_links_router.py:

@router.get("/quick-links")
def search_quick_links(limit: int = 10, offset: int = 0,
                       function_scope: FunctionScopeEnum = FunctionScopeEnum.VIEW,
                       user = Depends(<auth dependency>)):        # validates Okta token
    pagination = PaginationRequest(limit=limit, offset=offset)
    result = get_quick_links_service_singleton().search_quick_links(
        user_email=user.email, is_internal=user.is_internal,
        function_scope=function_scope, quick_link_ids=None, pagination=pagination)
    if isinstance(result, ErrorResponse):
        return JSONResponse(status_code=result.status_code, content=...)
    return result

Look for: which dependency validates the token, how user_email/is_internal are read, and who may use MANAGE scope.

Build service + DB connections SEEN

@lru_cache()                                    # created ONCE, reused for every request
def get_quick_links_service_singleton() -> "QuickLinksService":
    # Both services connect to portal_datastore (where FDWs and quicklinks tables exist)
    db_name = settings.get_property("database", "portal_db_name")
    db_user = settings.get_property("database", "portal_db_user")

    db_quicklinks   = get_manager().get_service(db_name=db_name, db_user=db_user)
    return QuickLinksService(db_entitlements, db_quicklinks)
  • settings.get_property → config (eas_utils.config), section [database].
  • get_manager().get_service → RDSProxyService = DB connection through AWS RDS Proxy.

5

Choose VIEW or MANAGE SEEN

if function_scope == FunctionScopeEnum.VIEW:
    rows = self._execute_view_query(self.db_quicklinks, user_email, is_internal, quick_link_ids, pagination)
else:
    rows = self._execute_management_query(self.db_quicklinks, user_email, quick_link_ids, pagination)

VIEW = end user sees links they are allowed to see. MANAGE = admin screen, also returns is_editable.

6

Parameters sent to the DB SEEN

VIEW — 9 params 
params_tuple = (
    user_email,        # 1 caller
    is_internal,       # 2 cpp_id filter
    is_internal,       # 3 NOT %s client specific
    is_internal,       # 4 internal sees all
    is_internal,       # 5 NOT %s external check
    quick_link_ids,    # 6 NULL check
    quick_link_ids,    # 7 ANY(%s)
    pagination.limit,  # 8 LIMIT
    pagination.offset, # 9 OFFSET
)
MANAGE — 5 params 
params = (
    user_email,        # CALLER_CTE auth
    quick_link_ids,    # NULL check
    quick_link_ids,    # ANY(%s)
    pagination.limit,
    pagination.offset,
)
rows = db.execute_query(GET_QUICK_LINKS_VIEW, params_tuple, fetch_one=False, use_named_tuples=True)
Why %s + tuple? Parameterized query — the driver inserts values safely (no SQL injection). Why repeated values? %s is positional; every place the SQL uses a value needs its own entry, in the same order.
7

The SQL that runs VERIFY

Real text is in quicklinks/sql/get_quick_links_queries.py. Expected shape (illustrative):

WITH caller AS ( SELECT ... WHERE email = %s ), ...
SELECT ql.id, ql.url_label, ql.category, ql.url, ql.open_in_new_tab, ql.display_order,
       ql.quicklink_display_start_date, ql.quicklink_display_end_date,
       ql.program, ql.program_instance, ql.model_type, ql.role_type, ql.special_feature, ql.cpp_id,
       CASE WHEN ql.quicklink_display_end_date < CURRENT_DATE THEN 'Expired' ELSE ql.status END AS status,
       ql.created_at, ql.updated_at, ql.created_by, ql.updated_by,
       COUNT(*) OVER () AS total_count          -- total ignoring LIMIT
FROM <quick links table> ql
WHERE ( ... is_internal / participation rules ... )
  AND (%s::int[] IS NULL OR ql.id = ANY(%s))
ORDER BY ql.display_order
LIMIT %s OFFSET %s;

Known facts: DB = portal_datastore (PostgreSQL via RDS Proxy); client data comes through FDW schema client_datastore (e.g. client_datastore.client_program_participant); SQL returns total_count; SQL sets Expired using CURRENT_DATE.

Copy the SQL into DBeaver/pgAdmin, replace each %s with a test value, and run it — the fastest way to learn it.

5. Build a NEW API the same way

Example: feature favorites with GET /v1/favorites.

1
Create folders (copy the quicklinks layout) 
favorites/  model/  router/  service/  sql/     (each with __init__.py)
2
Model — favorites/model/favorite_models.py 
class Favorite(BaseModel):
    id: int
    name: str
    url: str
    created_at: Optional[datetime] = None

class FavoriteListResponse(BaseModel):
    favorites: List[Favorite]
    pagination: Pagination
3
SQL — favorites/sql/get_favorites_queries.py 
GET_FAVORITES = """
    SELECT f.id, f.name, f.url, f.created_at,
           COUNT(*) OVER () AS total_count
    FROM <schema>.favorites f
    WHERE f.user_email = %s
    ORDER BY f.created_at DESC
    LIMIT %s OFFSET %s
"""
4
Service — favorites/service/favorites_get_service.py 
@lru_cache()
def get_favorites_service_singleton() -> "FavoritesGetService":
    db_name = settings.get_property("database", "portal_db_name")
    db_user = settings.get_property("database", "portal_db_user")
    return FavoritesGetService(get_manager().get_service(db_name=db_name, db_user=db_user))

class FavoritesGetService:
    def __init__(self, db):
        self.db = db

    def search_favorites(self, user_email: str, pagination: PaginationRequest):
        try:
            rows = self.db.execute_query(GET_FAVORITES,
                                         (user_email, pagination.limit, pagination.offset),
                                         fetch_one=False, use_named_tuples=True) or []
            total = rows[0].total_count if rows else 0
            items = [Favorite(id=r.id, name=r.name, url=r.url, created_at=r.created_at) for r in rows]
            return FavoriteListResponse(
                favorites=items,
                pagination=Pagination(total=total, limit=pagination.limit, offset=pagination.offset,
                                      result_set_id=None,
                                      has_more=pagination.offset + len(items) < total))
        except Exception:
            logger.exception("Error searching favorites")
            return internal_server_error(ERROR_CODE_RETRIEVING_DATA, ERROR_MSG_RETRIEVING_DATA)
