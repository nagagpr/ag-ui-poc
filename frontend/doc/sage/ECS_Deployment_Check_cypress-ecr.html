Check ECS Deployment: cypress-ecr

AWS CloudShell steps to confirm the cypress-ecr service is running, and to find out why the Application URL doesn't open in the browser after moving from the default VPC to the company VPC

Version
Version 1.0 · 19 October 2026
Audience
Application team, IT / Cloud team

Why the URL stopped working

What happens
BeforeWith the default VPC, Express Mode put the load balancer in public subnets, so it was internet-facing and the URL opened from any browser.
NowThe only VPC is the company VPC use1-dev-dse_local (vpc-0758ef1be26b0b173). Its subnets are usually private, so Express Mode creates an internal load balancer. The URL still resolves, but to private IPs, reachable only from inside the VPC or from a network connected to it (such as the company VPN).

The steps below confirm whether the application itself is healthy, and whether the load balancer is internal.
